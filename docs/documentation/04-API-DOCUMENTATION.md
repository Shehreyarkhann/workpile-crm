# Workpile — API Documentation

Generated from the production codebase at commit `6155c8a` (v6). **255 routes** across 27 server modules.

## Conventions

- **Base URL (pilot):** `https://workpile.claimpaid.io` — all routes below are under `/api` unless shown as a public path.

- **Auth:** session cookie (browser app) or `Authorization: Bearer <api_key>` (programmatic intake). Unauthenticated calls to protected routes return `401`. Plan-gated business routes return `403 PLAN_REQUIRED` when the workspace has no active plan/trial.

- **Tenancy:** every route operates inside the caller's workspace; there is no cross-workspace parameter.

- **Errors:** JSON `{ error: string, code?: string }` with conventional HTTP statuses (`422 seat_limit`, `409` double-sign/conflict, `402` plan-limit patterns where applicable).
